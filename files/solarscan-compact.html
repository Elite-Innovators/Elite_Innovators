HOW IT WORKS

Five steps. Address in,
report out.

Logged in the order a real surveyor would work — imagery first, geometry last, nothing skipped.

01

Address → imagery

The address is geocoded and matched to the highest-resolution tile covering that parcel, then cropped to the property boundary.

GEOCODE + TILE FETCH
02

Roof segmentation

A segmentation model traces the usable roof polygon — separating it from overhangs, tanks, stairwell heads, and shared walls — and returns true usable area.

U-NET / SAM
03

Shadow & sun-path modelling

Neighbouring building heights are estimated and projected against the sun's path through the year, producing an hour-by-hour shading map over the roof.

SUN-PATH GEOMETRY
04

Energy & financial modelling

Usable area and shading combine with irradiance modelling to estimate kWh/year, panel count, subsidy-adjusted cost, and payback period.

PVLIB IRRADIANCE
05

Vendor-ready report

Every figure is compiled onto a single page — roof drawing, shading summary, system size, cost — formatted so a vendor can quote directly from it.
